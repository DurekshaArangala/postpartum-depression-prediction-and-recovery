# Medical-Chatbot-with-LLMs-LangChain-and-PineCone

# How to run?
### STEPS:

clone the reposistory
```bash
git clone https://github.com/DurekshaArangala/Medical-Chatbot-with-LLMs-LangChain-and-PineCone.git
```

### Step 01: Create a virtual environment after opening the repository

```bash
py -3.10 -m venv venv
```

```bash
.\venv\Scripts\Activate.ps1
```


### STEP 02: Install the requirments
```bash
pip install -r requirements.txt
```
