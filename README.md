# Liyaa:  Explainable AI-Powered Conversational Mobile Health System for Early Detection and Personalized Recovery Support of Postpartum Depression

> 🚧 **Project Status:** Ongoing (Final Year Research Project)

## 📖 Overview

Liyaa is an ongoing Final Year Research Project that aims to develop an Explainable AI (XAI)-powered conversational mobile health system for the early detection and personalized recovery support of postpartum depression among Sri Lankan mothers.

The proposed system integrates machine learning, explainable AI, conversational AI, and mobile health technologies to provide early risk prediction, transparent explanations, personalized recovery guidance, and continuous mental well-being monitoring.

---

## 🎯 Objectives

- Develop a machine learning model for postpartum depression prediction.
- Provide transparent predictions using Explainable AI (SHAP).
- Develop a conversational AI chatbot for symptom assessment.
- Generate personalized recovery recommendations.
- Enable continuous emotional well-being monitoring.
- Evaluate prediction performance, explainability, usability, and user engagement.
